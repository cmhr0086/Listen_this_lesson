# Listen This Lesson

一款面向真实课堂场景的 Android 语音识别与 AI 辅助整理应用。它在设备端持续录制并用 Silero VAD 自然分段，再将语音发送到远程 ASR 服务；课程、课堂记录、识别文本和 AI 结果均按清晰层级保存在本机。

## 软件特色

- **持续课堂识别**：使用 AudioRecord 采集 16 kHz 单声道音频，ASR 处理期间不会停止监听。
- **自然语音分段**：Android 端仅使用 sherpa-onnx / Silero VAD 判断语音区间，不在手机上运行 ASR 模型。
- **先录后归档**：打开即可开始上课，录完再确认保存到哪门课；内容按“课程 → 课堂记录 → 识别片段”保存，并以段落形式按时间阅读。
- **一节课一个页面**：课堂页分“文字 / 笔记 / 问答”三栏；选中文字后直接复制、问 AI、标为重点或记成笔记。
- **重点标记**：上课时点控制栏或通知里的“标记重点”，当时那几句会被标出；整理笔记时重点会被突出。
- **自动笔记与搜索**：下课归档后自动整理整节课笔记并提炼主题；全文搜索所有课堂的文字和笔记。
- **课程 ASR Context**：每门课程可以维护专业词，并选择关闭、自动或始终使用提示词。
- **持久识别队列**：待处理片段会临时保存在应用私有目录，切到后台后仍可继续提交和查询异步任务。
- **AI 会话与整理**：支持兼容 OpenAI 接口的服务和 DeepSeek，可进行课堂问答、笔记整理、快速回答和 ASR 纠错。
- **原文安全保留**：AI 纠错作为独立纠正版应用，原始识别文本不会被覆盖，并可随时恢复。
- **丰富内容展示**：AI 回复支持流式生成、思考内容、Markdown、表格、代码块、图片及文本附件。
- **导出与诊断**：课堂记录可导出 UTF-8 TXT；开发者模式提供 VAD、队列和完整 ASR 生命周期诊断。
- **本地安全存储**：API Key 使用 Android Keystore 保护，不写入 Room、日志或导出文件。

## 安装

1. 打开 [GitHub Releases](https://github.com/cmhr0086/Listen_this_lesson/releases)。
2. 下载 `Listen_this_lesson-v1.3.1-arm64-v8a.apk`。
3. 在 Android 设备上允许当前安装来源，然后安装 APK。

当前正式安装包仅支持 `arm64-v8a`，最低系统版本为 Android 8.0（API 26）。

## 首次配置

### 1. 配置语音识别服务

进入“设置 → 语音识别”，点地址和 API Key 分别填写；确认后立即保存并自动测试，顶部状态卡显示是否可用、上次测试时间和失败原因。测试会真正校验 API Key。客户端使用异步任务式 STT 服务（`/transcribe` + `/jobs/{jobId}`），请确保服务端版本兼容。

### 2. 配置 AI 服务（可选）

进入“设置 → AI 服务”，选择 DeepSeek（地址自动填写）或“其他服务”（兼容 OpenAI 接口，需填地址），再选模型、填 API Key。模型在单独的选择页中从服务端获取，也可手动输入；改动会立即保存并自动测试。

不配置 AI 服务不会影响课堂录音、VAD 分段和语音识别。

### 3. 外观（可选）

进入“设置 → 外观”选择主题色（默认“墨青”）和深色模式。

### 4. 调整开发者选项（可选）

在设置页开启开发者模式后，可以在“VAD 预设与参数”里选预设并微调参数，编辑各个 AI 提示词和 AI 生成参数，调整专业词自动模式门槛，并进入 ASR 诊断页面查看队列和网络阶段。设置项改了即生效，只有提示词编辑页需要点“保存”。

## 使用教程

### 开始一节课

1. 打开 App 默认就是“录音”页。第一次使用时先给课程起个名字。
2. 在“开始上课”卡片上直接点录制方式，立即开始：
   - **实时转写**：边录边识别，文字实时出现在课堂页面，需要能连接 STT 服务。
   - **仅录音**：只在本机保存录音，不调用识别服务，适合网络不稳定或想先录下来的场景。
3. 卡片右上角预选了课程（按平时上这门课的星期几和时间猜测），可以点开更换。
4. 课间休息等需要临时停下时点“暂停”，回来后点“继续”，录音和计时接着同一节课；点“结束”才算这节课录完。
5. 结束后会询问“这节课保存到哪门课？”，直接保存或改选、新建课程即可。录错了也能在课堂记录菜单里“移到其他课程”。
6. 首次使用时授予麦克风权限；通知权限用于显示录制状态。录制期间可以切换页面，底栏“录音”图标会显示红点（暂停时为黄点）；在录音页、课堂页底部控制栏或通知中都可以暂停或结束。

### 课堂页：文字、笔记、问答

- **文字**：按时间合并成段落，每段标注开始时间。实时转写时自动跟随最新内容；往上翻阅时不打断，右下角会提示有几条新内容。
- **笔记**：整节课的 AI 笔记（配置了 AI 服务时，下课归档或录音识别完后自动整理，并写出这节课的主题），以及纠错建议、选段笔记等其他整理结果。
- **问答**：这节课的 AI 对话。底部直接提问，可选择带上“最近 10 分钟 / 整节课 / 不带原文”。

### 标记重点

上课时点底部控制栏的书签按钮，或锁屏通知里的“标记重点”，当时正在讲的那几句会标为重点（仅录音的课在识别出文字后自动标出）。课后也可以选中文字后“标为重点”或“取消重点”。重点会显示在课程列表里，整理笔记时会被突出，搜索时可“只看重点”。

### 搜索

在“录音”或“课程”页右上角点搜索，可以在所有课堂的文字（含纠正后的文字）和 AI 笔记里查找关键词，点结果直接打开那节课。

### 仅录音与稍后识别

- 仅录音时面板会显示“已安全保存”的时长。即使 App 被关闭、划掉后台或意外退出，已保存的录音也不会丢失，重新打开后会显示为“待识别”。
- 一节课暂停/继续过会有多段录音，课堂页把它们收进一张“录音文件”卡片：点“全部识别”按顺序识别所有待识别录音，识别结果按时间写入同一条课堂记录；可随时“暂停识别”，之后从中断处接着处理。展开卡片可逐段识别或删除。
- 录音只保存在本机，约 115 MB/小时，不会上传到云端。不再需要时可通过录音右侧菜单“删除录音”，已识别的文字会保留。

### 云同步

在“设置 → 云同步”填写 HTTPS 服务器地址和同步 Token 后，手动点击同步。同步只包含课堂记录、识别文字、重点标记和课堂主题，不包含录音、AI 对话和附件；多台设备之间以最后修改时间为准合并。重点标记和主题需要 1.3.0 起的同步服务端。

### 设置课程专业词

在课程页点“专业词提示”，填写课程中的人名、术语或专业词。自动模式只会为质量合适的语音片段附带 Context，降低短片段和噪声触发错误提示的概率。

### 整理和纠正识别内容

- 长按识别片段进入多选模式，继续滑动可以选择连续范围；点段落的时间标题可以选中或取消整段。
- 底部操作栏：复制、问 AI、标为重点、记成笔记，以及“更多”里的 AI 纠错和删除。
- 结构化纠错结果需要手动点击“应用全部纠正”；应用后仍可查看并恢复原文。
- 课堂页右上角菜单可以进入选择模式、导出 TXT 或编辑这门课的专业词。

### 使用 AI 会话

底栏“AI 会话”汇总所有课程的 AI 对话和结果，可按“课堂 / 自由提问”筛选，也可以新建不绑定课程的通用对话。聊天输入栏支持选择图片以及 TXT、MD、CSV、JSON 文本附件。

### 导出课堂内容

进入记录详情右上角菜单，选择“导出 TXT”，再通过系统文件选择器指定保存位置。导出内容包含课程、课堂记录时间以及按真实时间排列的识别文本。
