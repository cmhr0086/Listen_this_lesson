# 产品待办

来自 2026-11-03 一周实际使用后的反馈。方向是做减法。状态：`待定` 还没决定怎么做，`方案已定` 等开工，`完成` 已上线，`将被替换` 由下面的重构方案取代。

## 2026-11 重构方案（方案已定，验证中）

2026-11-09 讨论确定。起因：App 和小程序都别扭，要自己的 API、要绑定账号、要开小程序，找课程也费劲。

### 定位

从“我的录音工具”变成“西建大的课程中心”。课程目录由大家上传的课表自然生成，录音只是课程下的一种内容，不再是核心。只服务本校，学校固定。

### 已定

1. **课程结构**：课程按课程号区分，下面是教学班（老师 + 班号 + 学期）。资料可以挂在整门课，也可以挂在某个教学班。课程号不同但实际相同的课，由管理员手动合并。个人课表只用来匹配，不公开。
2. **课表驱动录音**：App 内有课表（复用 PDF 解析）。到点打开就能录，课程名、老师、周次、节次自动带出，发布不填表。
3. **同步**：去掉绑定码和设备管理，改用 WebDAV，以后再加 S3。配置和数据一起同步，换设备只填一组网盘账号。默认只同步转写和笔记，音频可选。
4. **发布**：只有我一个人录课，所以去掉审核。课程只有“公开”“隐藏”两种状态，可以按课程设为自动公开。服务端只认一个主人身份，凭据放在 WebDAV 配置里。后台去掉待审核、驳回、上传者、Token、设备管理、操作日志。
5. **减法**：删除最近课程、专业词提示、原文记重点。AI 保留，但改用法：以下课后自动生成笔记为主，对话入口收起，新增“复制给外部 AI”。
6. **登录**：App 不登录；读者不需要账号，小程序静默拿 openid 记住关注的课。微信开放平台登录需要个体户或企业资质，暂不考虑。
7. **技术**：用 uni-app x 一份代码出 Android App、小程序、网页阅读端。现有 Kotlin 录音核心（Silero VAD、前台服务、转写上传）保留，做成 UTS 原生插件。沿用包名 `com.cmhr.listen`，旧数据经 WebDAV 迁移。只要求在当前主流机型上好用，不再兼顾 Mate 9。新工程放在 `/Volumes/Data/project/listen-x`。
8. **暂不做**：iOS（原生和 Safari 网页录音都不做）。

## 优先

### 统一设备管理和配置向导（完成）

2026-11-03 上线：服务端 0.6.0、App 1.7.0。主力机要绑定一次，把现有配置传到云端。第一版只支持输入绑定码，没有做扫码，也没有异地设备提醒。

对应反馈：换设备要输入 4 个密钥，不合理。AI 服务、语音识别、云同步、公开发布的配置应保存在云端，用户也可以修改，首次使用走配置向导。

设备绑定：

- App 不做微信登录，也不需要预先配置，只内置服务器地址。
- App 申请绑定，屏幕显示绑定码，并持有一个只有它知道的随机凭据。
- 用户在小程序（微信一键登录）里输入或扫描绑定码，看到设备型号和申请时间后点“允许”。
- App 用随机凭据领取设备凭证和配置，存进本机 Keystore。
- 绑定码 5 分钟有效，只能用一次，限制输错次数。第一版只有管理员账号能批准。
- 小程序新增“我的设备”：查看、移除。任何一端改配置，其他设备都会收到更新。

密钥和服务端：

- 放在 `listen-publish`，用服务器主密钥加密后入库，数据按账号存。
- 云同步和公开发布由服务端自动配好。多台设备共用一个上传者。
- 移除设备不等于更换密钥。手机丢失时要去更换 AI Key 等密钥。
- 第一次迁移要由现在这台手机上传配置，因为 AI Key 和上传 Token 取不回明文。

配置向导：

- 全新安装才进入。绑定后云端已有配置就直接进首页。旧版本升级不打断，只在设置页顶部提示绑定。
- 步骤：绑定（或手动配置）→ 语音识别 → AI 服务（可选，默认 DeepSeek）→ 完成页列出四项状态。
- 每步都能跳过，中途退出下次继续。测试失败显示原因，可以仍然保存，因为识别服务在 Mac 上，可能没开。
- 向导里不放专业词提示、VAD 阈值、提示词。手动配置不问同步和发布。

待核实：能否从 App 一键跳到小程序，取决于微信对小程序主体类型的限制。绑定码方式一定可行。

开工顺序：提交资料功能代码 → 服务端 → 小程序 → App 向导和配置同步 → 上线后迁移现有配置。

### 后台重构（已上线）

2026-11-04 调整方向，取代之前“只留小程序、下线网页”的想法：

- 网页后台保留，用现成后台方案重构，不受微信界面风格限制，课程多时在网页上细致管理。
- 小程序保留随手处理（待处理、课程、读者），两边共用同一套接口。
- 新增同步管理和存储占用：总占用、各部分占用、同步的课堂和段落数量。
- 上传不再需要上传 Token，靠微信绑定的设备鉴权；上传者变成账号上的一项权限。
- 课程只分三类：已公开、待审核、已打回。已下架和已驳回合并成已打回；侧边栏的“课程”展开成这三类，每一类的操作相同。
- 操作规范：列表只看；当前状态做不了的操作不出现；驳回和下架必须写原因；删除二次确认；日志记录是谁做的。
- 2026-11-04 上线：publish 0.7.0、sync 1.4.0、App 1.8.0、小程序 1.8.0。
