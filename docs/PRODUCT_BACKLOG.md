# 产品待办

来自 2026-11-03 一周实际使用后的反馈。方向是做减法。状态：`待定` 还没决定怎么做，`方案已定` 等开工，`完成` 已上线。

## 优先

### 统一设备管理和配置向导（代码完成，等上线）

代码已提交；服务端 0.6.0 还没部署，绑定流程还没有端到端跑通。上线后要先用主力机绑定一次，把现有配置传到云端。第一版只支持输入绑定码，没有做扫码。

对应反馈：换设备要输入 4 个密钥，不合理。AI 服务、语音识别、云同步、公开发布的配置应保存在云端，用户也可以修改，首次使用走配置向导。

设备绑定：

- App 不做微信登录，也不需要预先配置，只内置服务器地址。
- App 申请绑定，屏幕显示绑定码，并持有一个只有它知道的随机凭据。
- 用户在小程序（微信一键登录）里输入或扫描绑定码，看到设备型号和申请时间后点“允许”。
- App 用随机凭据领取设备凭证和配置，存进本机 Keystore。
- 绑定码 5 分钟有效，只能用一次，限制输错次数。第一版只有管理员账号能批准。
- 小程序新增“我的设备”：查看、移除。任何一端改配置，其他设备都会收到更新。

密钥和服务端：

- 放在 `listen-publish`，用服务器主密钥加密后入库，数据按账号存。
- 云同步和公开发布由服务端自动配好。多台设备共用一个上传者。
- 移除设备不等于更换密钥。手机丢失时要去更换 AI Key 等密钥。
- 第一次迁移要由现在这台手机上传配置，因为 AI Key 和上传 Token 取不回明文。

配置向导：

- 全新安装才进入。绑定后云端已有配置就直接进首页。旧版本升级不打断，只在设置页顶部提示绑定。
- 步骤：绑定（或手动配置）→ 语音识别 → AI 服务（可选，默认 DeepSeek）→ 完成页列出四项状态。
- 每步都能跳过，中途退出下次继续。测试失败显示原因，可以仍然保存，因为识别服务在 Mac 上，可能没开。
- 向导里不放专业词提示、VAD 阈值、提示词。手动配置不问同步和发布。

待核实：能否从 App 一键跳到小程序，取决于微信对小程序主体类型的限制。绑定码方式一定可行。

开工顺序：提交资料功能代码 → 服务端 → 小程序 → App 向导和配置同步 → 上线后迁移现有配置。
